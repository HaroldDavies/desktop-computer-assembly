# Desktop Computer Assembly & Disassembly

Interactive 3D web application for assembling and disassembling a desktop computer.

## Files

- `index.html` — Main page
- `app.js` — Application logic and 3D models (bundled)

## How to run

1. Clone the repository
2. Open `index.html` in a modern browser (or use a local server)

```bash
# Optional: serve with a simple local server
python -m http.server 8000
# then open http://localhost:8000
```

## About

This project demonstrates the assembly and disassembly process of a typical desktop computer in an interactive 3D environment.
